## Speaker identity

The owner reports changing voices and uneven conversation. Today's independent speech comparison could not run because the secure endpoint was unreachable, so the audible symptom has not yet been independently reproduced.

VoxCPM's documentation states that no-reference generation does not preserve timbre across calls. The pinned vLLM-Omni v0.32.0 example supports `ref_audio`; its precomputation example also supports fixed custom voice profiles.

Sources:
- https://voxcpm.readthedocs.io/en/latest/usage_guide.html
- https://github.com/vllm-project/vllm-omni/blob/v0.32.0/examples/online_serving/text_to_speech/voxcpm2/openai_speech_client.py
- https://github.com/vllm-project/vllm-omni/blob/v0.32.0/examples/online_serving/text_to_speech/voxcpm2/precompute_custom_voice.py

Proposed approach: preserve VoxCPM2, generate/select one synthetic SOULBOUND reference, and use the same conditioning for every reply. No real-person recording or identity cloning. Ticket 035 scopes an opt-in implementation and requires live comparison and owner listening before acceptance. Existing voice policy requires an explicit decision before activating reference conditioning.
