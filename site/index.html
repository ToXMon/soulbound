03Blockchain Layer — Solana = Identity & Memory

The character IS a Metaplex Core asset. Its life history is a Merkle root chain.

🧬 Attributes plugin
Live trait state on-chain: personality vector, life stage, mood, memory count. Judges watch traits mutate on the explorer after talking to it.
🛡 Oracle plugin
Lifecycle REJECT gates trait mutation to the verified runtime signer. The contract refuses unauthorized personality edits.
🔒 Token-2022 non-transferable
The soulbound receipt. Ownership can never be sold or moved. It is yours, permanently.
📜 Verifiable memory lineage — "a childhood you can audit"
Spark extracts episodic memories → Merkle tree → Anchor program commit_memory_root anchors the root on Solana devnet. Any single memory is inclusion-provable without revealing private content. Instructions: initialize_character · commit_memory_root · evolve_traits (oracle-gated) · crank_heartbeat (permissionless life-stage crank). Tests: LiteSVM. Client: gill/Solana Kit.
